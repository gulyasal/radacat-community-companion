# First community preview — C1 public messaging

An unofficial Android and Windows companion for Radacat C1 owners. No vendor account or vendor server is required.

Includes short public messages with sender names, optional clickable coordinates, Android incoming-message notifications/background connection, and Windows automatic reconnection with a matching conversation UI.

Tested hardware: TomCat II Note / device model 6 / firmware 1.0.0. Tested hosts: Pixel 9a, Android 12 phone, and Windows 11. This does not establish compatibility with all C1 variants or phone versions.

Use group 2222 / channel 0. Messages and coordinates are unencrypted. Bluetooth acceptance is not a delivery receipt. This is an early preview; do not rely on it for emergencies. Original-app readable compatibility, voice, private teams and independent mesh relaying are unverified or unsupported.

Downloads:

- Android APK: signed community preview. Existing private test builds with a different signing key cannot update in place; see README before uninstalling anything.
- Windows ZIP: standalone 64-bit EXE, icon and dependency license notices. Extract and run; Python is not required. The preview EXE is not Authenticode signed.
- Source ZIP: Android and desktop sources, tests and build instructions.
- SHA256SUMS.txt: download integrity checksums.
